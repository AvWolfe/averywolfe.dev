Systems, mostly

Roughly 74,000 lines of C# across 500 source files, all of it mine — I'm the only engineer on the project. Most of it is machinery the player never sees directly, which is the part I find worth building.

Enemies that disagree with each other

  • Reckless
  • Bloodthirsty
  • Berserker
  • Cautious
  • Cowardly
  • SelfPreserving
  • Opportunistic

Every unit runs the same planner: score the available moves, the lines of sight, the abilities, pick the best one, repeat until the turn is spent. Traits don't add special-case behaviour, they change what "best" means. A Cowardly unit and a Berserker read an identical board and reach opposite conclusions.

Modding as a first-class path

Two tiers. Sandboxed JavaScript for interface work, and full-access C# plugin assemblies for everything else. The C# tier hot-reloads: rebuild a mod while the game is running and it swaps in without a restart.

That loader is open source as GodotModKit, usable in any Godot 4 .NET project, MIT licensed.

Loadouts that name themselves

Modifier augments slot into ability augments, which slot into the character. A weapon is a small stack of decisions rather than a number that goes up.

Names are built from what's installed, not written by hand. A mod contributes exactly one word, those words fuse across the stack, and the whole thing is capped at two — so Light Shot becomes Toxic Light Shot when a poison mod goes in, and Burning over Toxic resolves to Phlogiston. Pull the mod back out and the name reverts.

Two of the slots are about losing. A Reaction augment fires when its holder is hit and lives; a Failsafe fires when its holder dies — a revive, a parting shot, a blast that takes the room with it. Getting hurt and getting killed are both things you can build for.

The rest of it

A* pathfinding with per-unit clearance, and a separate line-of-sight grid so bodies don't block shots the way terrain does. An energy-ordered turn timeline you can read ahead of. A day and night cycle. Input rebinding driven by data rather than a hardcoded map. A HUD drawn in code so it can be reskinned by a mod.
